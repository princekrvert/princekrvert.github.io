# Prince Kumar portfolio

- index.html: page content (sections: hero, about, what I do, book, projects, connect)
- style.css: all styling. Colours and theme are CSS variables at the top (:root)
- script.js: theme toggle, scroll reveal, 3D hero scene
- assets/: photo.jpg (hero portrait), book-cover.jpg (book cover)

Open index.html in a browser. The 3D scene loads Three.js (r128) from cdnjs, so it needs internet.
To add a feature: put markup in index.html, styles in style.css, behaviour in script.js.
